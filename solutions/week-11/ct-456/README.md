## 제출 방법

```bash
git switch -c solve/week-11-ct-456-$(git config user.name)
mkdir -p solutions/week-11/ct-456/<본인-github-아이디>
# solutions/week-11/ct-456/<본인-github-아이디>/Solution.java 에 풀이 작성
```

- 폴더 이름은 **본인 GitHub 아이디**와 정확히 같아야 합니다.
- 파일은 `.java`만 올립니다. 클래스명 충돌을 막기 위해 사람마다 폴더를 분리합니다.
- 다른 사람 폴더는 건드리지 않습니다. (PR 검사에서 막힙니다)
- 풀이를 여러 개 내려면 본인 폴더 아래에 하위 폴더로 나누세요. 예) `solutions/week-11/ct-456/<아이디>/v1/Solution.java`, `.../v2/Solution.java` (폴더마다 따로 컴파일)
