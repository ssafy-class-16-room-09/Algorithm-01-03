
- 풀이를 여러 개 내려면 본인 폴더 아래에 하위 폴더로 나누세요. 예) `solutions/week-06/pgs-92343/<아이디>/v1/Solution.java`, `.../v2/Solution.java` (폴더마다 따로 컴파일)
